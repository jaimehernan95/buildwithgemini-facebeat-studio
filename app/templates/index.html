1. macOS System Settings (MacBook Requirement):
macOS blocks Chrome/Safari from accessing your webcam unless explicitly allowed in System Settings:
Apple Menu () ➜ System Settings ➜ Privacy & Security ➜ Camera ➜ Toggle Google Chrome (or Safari) to ON
2. Browser URL Bar Permission:
In Chrome/Brave/Edge next to localhost:8000 in your address bar, click the Tune / Lock icon ➜ Set Camera to Allow, then reload.
3. If accessing remote Linux server from MacBook:
Browsers disable webcams on remote HTTP IP addresses (e.g. http://192.168.x.x:8000).
To use your MacBook camera, forward port 8000 via SSH from your Mac terminal:
ssh -L 8000:localhost:8000 user@server-ip
Then open http://localhost:8000 in your Mac browser.
